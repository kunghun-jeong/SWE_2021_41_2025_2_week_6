## 2. Selected License: **MIT License**

I selected the **MIT License** for this Week 6 assignment.

### ✔ Why I chose the MIT License
1. **Very simple and widely used**  
   - MIT is one of the most popular open-source licenses.  
   - Easy for others to understand and reuse.

2. **Permissive license**  
   - Anyone can copy, modify, distribute, or use the code with almost no restriction.  
   - Only requirement is to include the copyright notice.

3. **Fits educational material**  
   - This repository contains basic Git practice files, which are not sensitive or proprietary.  
   - A permissive license is appropriate for simple examples and educational content.

4. **Low legal complexity**  
   - Compared to GPL or Apache License 2.0, MIT has minimal legal constraints.  
   - Ideal for small repos or student assignments.
